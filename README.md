# AR Car Showroom — Unity 6.3 LTS (6000.3.25f1)

Ready-to-open Unity project for Android AR using AR Foundation and Google ARCore.

Features: plane detection, tap-to-place procedural car, color changes, door animation, headlights, engine/wheel animation, gestures, info/reset UI.

The car is generated from Unity primitives, so no external FBX/model download is required.

Open this folder in Unity Hub with **Unity 6000.3.25f1**. On first import, the included editor setup creates `Assets/ARCarShowroom/Scenes/ARCarShowroom.unity` and the car prefab automatically.

For Android, switch the project to Android in Build Profiles and build on an ARCore-supported phone.

Unity's current documentation lists AR Foundation 6.3.x and ARCore 6.3.x as released package lines, and XR Origin replaces the older AR Session Origin in modern AR Foundation.
